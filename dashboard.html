임상 관찰
어렸을 때부터 시력 저하. 원데이 렌즈 착용자. 현재 눈 염증 심화로 안경 착용 중. 원인 불명. 악화 시 시력 손실 위험. 현재 염증 심해 라섹·렌즈삽입술 불가. 안과에서 윤부 줄기세포 손상 언급. 평소 거북목(Forward Head Posture) 심한 체형.
핵심 가설
  1. 후두하근 과긴장 → 추골동맥 압박 → 뇌 후두엽·안구 혈류 감소 → 윤부 줄기세포 영양 공급 저하
  2. C1-C2 부정렬 → 경정맥 환류 저하 → 안압 상승 → 줄기세포 재생 환경 악화
  3. 교감신경 항진 → 전신 염증 반응 악화 → 안구 염증 지속
  4. 전정-안구반사(VOR) 교란 → 안구 근육 과부하 → 안구 피로 가중
연결 체인
거북목 → 후두하근 과긴장 → ①추골동맥 압박·안구 혈류 감소 + ②C1-C2 부정렬·안압 상승 + ③교감항진·염증 악화 + ④VOR 교란·안구 과부하 → LSCD 재생 환경 저하
